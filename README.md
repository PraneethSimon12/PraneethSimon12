### 🚀 Currently building

**Paytm Pakka · *Kachha khata, pakka credit***

Paytm hears every UPI payment in a kirana shop, but it can't see the cash sales or the udhaar notebook. Paytm Pakka lets a shopkeeper record those by voice on the Soundbox. It then checks them against UPI (a *kachha* entry turns *pakka* when the repayment arrives) and uses those checked records to unlock fairer loans.

`Python` · `NiceGUI / FastAPI` · `SQLite` · `Gemma (on-device, via Ollama)` · `Sarvam AI speech` · `Hindi + English`
